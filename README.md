# AURIX Frontend

A modern e-commerce frontend built with Next.js, React, Tailwind CSS, ShadCN UI, Zustand, React Query, and Framer Motion.

## Features

* Authentication (Login / Register)
* Protected Routes
* Product Listing & Filtering
* Product Details Page
* Cart Management
* Wishlist Management
* Order Tracking
* Responsive Design
* Mobile Navigation Drawer
* React Query Data Fetching
* Zustand State Management

## Tech Stack

* Next.js 16
* React
* TypeScript
* Tailwind CSS
* ShadCN UI
* Zustand
* TanStack React Query
* Axios
* Framer Motion
* React Hook Form
* Yup Validation

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Environment Variables

| Variable            | Description     |
| ------------------- | --------------- |
| NEXT_PUBLIC_API_URL | Backend API URL |
